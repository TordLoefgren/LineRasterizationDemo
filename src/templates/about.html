About

Line Rasterization Demo is an interactive application for visualizing how line-drawing algorithms select cells on a grid. Users can configure the grid, position the line endpoints with sliders or direct canvas interaction, and see the rasterized result update immediately.

Purpose

I am building this project to strengthen my frontend development skills through a concrete technical problem. It also serves as groundwork for a future occupancy-grid application, where line rasterization can be used for grid-based ray casting.

Implementation

The first version uses vanilla HTML, CSS, and TypeScript so I can work directly with the web platform and better understand the problems that frameworks solve. The application uses URL-based routing, while demo state lives outside the routed views and is preserved during client-side navigation. State transitions are implemented as pure functions that return new state objects.
