Algorithms

This demo currently implements Bresenham's line algorithm.

Bresenham's line algorithm

Bresenham's algorithm approximates a straight line by selecting neighboring grid cells using an accumulated error value.

This implementation supports every line direction and returns the selected cells in order from endpoint A to endpoint B.

The implementation follows the all-octants pseudocode in A Lab Exercise for Rasterizing Lines by David J. Stahl Jr. (Figure 3).
